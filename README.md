Whiterinth is an unofficial fork of [Modrinth App](https://github.com/modrinth/code), based on the latest upstream release, **v0.23.5**. It is independently maintained and is not affiliated with or endorsed by Modrinth.

## Changes

**Removed**
- Advertising
- Modrinth Hosting from the sidebar
- The news feed

**Added**
- A monochrome design throughout the app

## Install

Go to [Releases](https://github.com/plsfr/whiterinth/releases/latest), download the latest Windows x64 installer from **Assets**, and run it.
